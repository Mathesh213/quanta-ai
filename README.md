🚀 Getting Started

Clone the repository:

git clone https://github.com/Mathesh213/quanta-ai.git

Move into the project folder:

cd quanta-ai

Install the required dependencies:

npm install

🔑 Environment Setup

The .env file is not included in this repository for security reasons.

Create a file named .env inside the quanta-ai project folder.

Add your own Gemini API key in the following format:

VITE_GEMINI_API_KEY=YOUR_GEMINI_API_KEY

Replace YOUR_GEMINI_API_KEY with your own Gemini API key.

⚠️ Do not upload or share your .env file or Gemini API key publicly.

▶️ Run the Project

After configuring the .env file, start the development server:

npm run dev

Open the local URL shown in your terminal to view the application.
